# distance-calculator

## This repository converts kilometers to miles :p

## How to Run
1. Open the program file in VS Code, Replit, or Google Colab.
2. Run the program.
3. Enter the values for x (kilometers).
4. Check the distance displayed on the screen.
5. If you want to convert another distance to miles, type yes. Otherwise, type no.

## Input Needed
- x
- a


## Sample Output
Enter distance in kilometers: 23
Distance in miles: 14.291533
Do you want to convert another distance? (yes/no): no
Program ended.
